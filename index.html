$ cat 02-event-data-capture.md

Event-triggered data capture

90%smaller ROS bags by recording only high-value topics.

50%less time to access field data after improving bag recording and cloud upload.

problem
Recording all LiDAR all the time is expensive to store and move, and the moments engineers need get buried.
what I built
  • LiDAR recording triggered by events instead of recording everything
  • Mission-bag upload to S3 so engineers could pull the data and debug field issues
